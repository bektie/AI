# Экспертные системы и искусственный интеллект — лабораторные №1–3

**ОмГТУ, 2026 год.** Комплект подготовлен по заданию пользователя и на основе предоставленного руководства «Малая экспертная система 2.0. Редактор баз знаний 1.0», а также примеров структуры отчётов из архива «Рабочий стол.zip».

## Содержание

- `src/build_kb.py` — генератор базы знаний (22 свидетельства / 10 гипотез).
- `src/БЗ_языки_программирования_UTF8.txt` — база знаний в формате МЭС, UTF-8.
- `src/БЗ_языки_программирования_МЭС_cp1251.txt` — **та же самая база знаний**, кодировка Windows-1251 для старой МЭС 2.0.
- `src/expert_system.py` — ЛР №2: консольная экспертная система на Python, **загружает БЗ из файла ЛР №1**.
- `src/kmeans_lab3.py` — ЛР №3: k-means с выбором начальных центров k-means++, графиками сходимости и кластеров.
- `src/requirements.txt` — пакет matplotlib для создания графиков ЛР №3.
- `tests/test_labs.py` — модульные проверки формата БЗ, формулы Байеса, 10 профилей языков и k-means.
- `output/` — реальные результаты запуска программ, изображения графиков, CSV.
- `reports/` — три редактируемых отчёта Word, заполнить ФИО и группу перед сдачей.

## Запуск

**Лабораторная №1:** открой `БЗ_языки_программирования_МЭС_cp1251.txt` в редакторе баз знаний МЭС 2.0 на совместимой Windows, выполни проверку и консультацию; сделай **собственные** скриншоты окон программы. Старая Windows-программа **не запускалась и не проверялась** в этой среде — мы подтверждаем только формат файла и успешное чтение нашим парсером.

В терминале из папки `src`:

```bash
python build_kb.py
python expert_system.py --list
python expert_system.py --demo Python
python expert_system.py --demo Kotlin
python expert_system.py
```

Для чтения CP1251-файла напрямую:

```bash
python expert_system.py --kb БЗ_языки_программирования_МЭС_cp1251.txt --demo Rust
```

Лабораторная №3:

```bash
python -m pip install -r requirements.txt
python kmeans_lab3.py
```

Если matplotlib не установлен, для расчёта без графиков:

```bash
python kmeans_lab3.py --no-plots
```

Проверка:

```bash
python -m unittest discover -s tests -v
```

## Важные научные замечания

- В БЗ заложены **условные экспертные оценки**, а не вероятности, рассчитанные по реальной статистике использования языков. Не представляй оценки как научно измеренную распространённость или точность.
- `expert_system.py` использует байесовское обновление **каждой гипотезы отдельно**, аналогично принципу из руководства МЭС. Поэтому проценты различных языков **не обязаны в сумме составлять 100%**. Это отдельные оценки правдоподобия гипотез по выбранной модели.
- У программы МЭС 2.0 из методички указана совместимость с Windows 95/98/Me и проверка на x86 XP/Windows 7. На современных Windows возможны проблемы, а на Mac нужна виртуальная Windows или другой совместимый способ запуска.
- Графики в отчётах — результаты `kmeans_lab3.py`, а не скриншоты чужой работы.
- В отчётах оставлены поля `[ФИО]`, `[Группа]`, `[Преподаватель]` для заполнения.

## Пример по формуле Байеса

Если вероятность языка `Python` до ответов равна `0.1`, то при положительном ответе на вопрос о машинном обучении и экспертных оценках `P(да|Python)=0.92`, `P(да|не Python)=0.08`:

`P(Python|да) = (0.92 * 0.1) / (0.92 * 0.1 + 0.08 * 0.9) ≈ 0.5610`.
